# AGENTS.md

Read and follow `CLAUDE.md` before working in this repository.

## Writing

Use the repository-scoped `$humanizer` skill in `.agents/skills/humanizer/`
whenever you create or edit user-facing prose. This includes documentation, the
explainer, reports, release notes, and pull request or commit text.

Run the skill's draft, audit, and final pass before publishing an artifact.
Preserve facts, code blocks, frontmatter, data, and link targets. Follow the
skill's invocation mode for the task. Unless a user-provided writing sample calls
for a different style, final prose must contain no em or en dashes.
